# 白盒测试用例
示例伪代码：
if(a>1 && b==0){
    x = x / a;
}
if(a==2 || x>1){
    x = x + 1;
}

## 判定覆盖
| 用例 | a | b | x | 判定1 | 判定2 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| W001 | 2 | 0 | 3 | T | T |
| W002 | 1 | 1 | 1 | F | F |

## 语句覆盖
| 用例 | a | b | x | 执行路径 |
| ---- | ---- | ---- | ---- | ---- |
| W003 | 2 | 0 | 3 | 全部语句执行 |
