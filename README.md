# 🧪 software-test-demo 软件测试示例项目
本仓库用于存放软件测试实验资料，包含黑盒测试、白盒测试用例、测试报告，适合简历展示、课程作业。

## 📋 内容清单
- 黑盒测试：等价类划分、边界值分析、场景法用例
- 白盒测试：语句覆盖、判定覆盖、条件覆盖用例
- 测试报告模板
- 测试缺陷（bug）报告模板

## ✅ 测试方法说明
1. 等价类划分：把输入划分为有效等价类、无效等价类，减少用例数量
2. 边界值分析：重点测试输入边界点（min、min+1、max、max-1）
3. 场景法：梳理业务流程，覆盖正常流程、异常流程
4. 白盒覆盖：语句覆盖、判定覆盖、条件覆盖、路径覆盖
